# 2048 Balls 3D — Honor/Huawei Remake

This project is a faithful recreation of the lost **2048 Balls 3D** game that originally existed only on Huawei HiApp / HiSpace between 2014–2016.  
The original game featured:

- Wooden frame play area  
- Colored numbered balls  
- Physics-based merging  
- Infinite number progression (BigInt)  
- Level-based gameplay  
- No ads, no shop, no skins  

This remake aims to preserve the original gameplay as accurately as possible.

## How to Play
- Click anywhere on the canvas to spawn a ball.  
- Balls fall with physics and merge when touching identical values.  
- Numbers double infinitely using BigInt.

## How to Run
Just open `index.html` in any browser.

## Project Structure
index.html      # main page
style.css       # wooden frame + canvas styling
game.js         # physics, merging, infinite numbers


## Why This Exists
The original game was lost when Huawei discontinued HiApp archives and the Honor 6 device broke.  
This project preserves the gameplay so it can be played forever.
